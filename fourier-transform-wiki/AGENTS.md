# AGENTS.md — Fourier Transform LLM Wiki

## 1. 專案目的與狀態
建立供「具有基本微積分基礎的大學生」閱讀的工程數學傅立葉轉換 LLM Wiki，並以已核准的 Wiki 為唯一教學內容依據，製作 10–12 頁可於瀏覽器瀏覽的圖解互動式 HTML 簡報。
目前狀態：**架構已建立；0 篇資料已 ingest；尚未產生簡報**。不得將規劃、草稿或未核准資料標為已完成。

## 2. 已確認需求（10/10）
1. 讀者：具微積分基礎的大學生。
2. 範圍：傅立葉級數與轉換關係、定義、常見性質、基本計算及工程應用。
3. 資料：大學公開教材及可信教學網站；至少 ingest 5 篇**可辨識的獨立資料**。
4. 語言：繁體中文為主，保留英文專業術語。
5. 引用：Wiki 與簡報末尾列資料名稱及網址；內部保留主張與來源對照，便於查證。
6. 衝突：比較來源差異，統一傅立葉轉換的符號、頻率變數、2π 及正反轉換慣例；不可把不同慣例直接當錯誤。
7. Ingest：**逐篇處理、逐篇人工確認**。未經使用者明確核准，不得進入下一篇。
8. HTML：10–12 頁，圖解、時域/頻域圖、公式、計算例題、可操作互動圖表。
9. 驗證：可執行的自動檢查＋人工驗收；檢查來源、公式一致性、內容、頁數、互動、排版。
10. Loop：每個自動修正節點最多 3 輪；未通過即停止並寫入錯誤報告，等待人工處理。

## 3. 不可違反的工作規則
- **先討論、後生成**：需求已獲確認；此後所有重大範圍變更需再次確認。
- **不得批次 ingest**；每次只挑 1 篇來源，建立來源紀錄與候選知識摘要，交使用者核准後才寫入正式 Wiki。
- 未經確認的資料只能放在 raw/ 或 drafts/；正式 wiki/concepts/ 僅放已核准內容。
- 每項重要定義、公式、性質、例題都保留可追溯的 source ID 與來源段落/章節；公開呈現只要求基本引用。
- 不得捏造來源、網址、頁碼、公式、執行紀錄或測試結果。無法查證的內容標記「待確認」。
- 對來源衝突先記錄差異、解釋可能的慣例差別，再選用全專案統一慣例；無法確認時停下詢問。
- 簡報只使用已核准的 Wiki 內容。排版階段不可自行新增學術主張或改動公式。
- 數學說明以易懂繁體中文呈現；在一般純文字紀錄中，分式使用 a/b、指數使用 ^。HTML 可採可讀且經驗證的公式呈現。
- 不得宣稱程式、瀏覽器、連結或人工驗收「通過」，除非實際執行或獲得使用者確認。

## 4. Wiki ingest 閘門（每篇必經）
A. 提出 1 篇候選來源：標題、作者/機構、網址、類型、與主題相關性。
B. 檢查網址可訪問、來源可辨識、內容與既有資料重複情況。
C. 擷取候選摘要與概念/公式證據卡；記錄來源 ID、章節、公式慣例及不確定處。
D. 執行一致性與來源核對；呈現結果，**等待使用者明確同意**。
E. 核准後才正式 ingest，更新 wiki/index.md、wiki/log.md、來源清單與知識頁。
F. 未核准/需修正：只修本篇，不開始下一篇。至少 5 篇核准後才能進入簡報產生階段。

## 5. Graph 與退回路線
候選來源 → 來源驗證 → 候選摘要/證據卡 → 公式/內容檢查 → 人工核准 → Wiki ingest → Wiki 覆蓋率檢查 → 教學大綱 → 逐頁稿 → 忠實度檢查 → HTML 渲染 → 功能/排版檢查 → 人工驗收 → 交件。
- 來源無效：退回候選來源。
- 公式或證據有問題：退回本篇摘要/證據卡；不可跳過人工核准。
- Wiki 少於 5 篇或缺少必要概念：停在 Wiki 覆蓋率檢查，補來源及人工確認。
- 大綱覆蓋不足：退回大綱，必要時退回 Wiki 查詢。
- 逐頁稿不忠於 Wiki：只退回錯誤頁的逐頁稿。
- HTML 互動或排版錯誤：退回 HTML 渲染；不可藉修版修改學術內容。
- 自動修正每個節點最多 3 輪；未通過則停止、留下檢查報告，請使用者決定。

## 6. 完成標準
- 至少 5 篇不同來源各自有核准紀錄及 Wiki 條目。
- Wiki 有索引、來源清單、定義/公式慣例與必要概念。
- HTML 為 10–12 頁，瀏覽器可正常瀏覽，頁面切換與互動圖表有實測紀錄。
- 檢查報告可追溯 Wiki → 簡報內容，並記錄各節點失敗、修正次數與結果。
- 反思以真實紀錄回答最常出錯的節點、檢查前移位置與 Graph 修改理由；無真實觀察不得虛構。
- 最終由使用者人工驗收。

## 7. 檔案職責
- raw/：候選來源原始材料（注意授權，不儲存機密或個資）。
- wiki/index.md：Wiki 導覽、來源與核准進度。
- wiki/concepts/：僅放核准知識條目。
- wiki/log.md：逐篇 ingest 與人工核准紀錄。
- cards/：證據卡（附來源 ID）。
- drafts/：待確認摘要、大綱及逐頁稿。
- slides/deck.html：核准後的 HTML 簡報（目前不存在）。
- workflow.md：Graph、Loop、退回路線與停止條件。
- checks/：自動檢查腳本及結果（尚未執行）。
- report.md：實際執行與反思（不得預填虛構結果）。
