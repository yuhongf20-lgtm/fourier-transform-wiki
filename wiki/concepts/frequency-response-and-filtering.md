# 頻率響應與濾波

## 傅立葉轉換慣例（S03，§2.1，頁 73；S01，投影片 8.4；S02，投影片 3）

S03 以 s 表示一般頻率（t 以秒計時為 Hz），i 為虛數單位。S02 用 f 表示相同頻率變數，j 與 i 都表示虛數單位。以下以 v(t) 示範 S03 原始慣例與 Wiki 的轉換對。

- S03 正轉換：`V(s) = ∫_{−∞}^{∞} v(t)e^(−2πist) dt`。
- S03 反轉換：`v(t) = ∫_{−∞}^{∞} V(s)e^(+2πist) ds`。
- Wiki 正轉換：`V(ω) = ∫_{−∞}^{∞} v(t)e^(−jωt) dt`。
- Wiki 反轉換：`v(t) = (1/(2π)) ∫_{−∞}^{∞} V(ω)e^(+jωt) dω`。

令 `ω = 2πs`、`ωc = 2πνc`。以 s 和 ω 為引數的同名頻域函數分別表示原文與 Wiki 慣例，例如 `H_ω(ω) = H_s(ω/(2π))`。反轉換換元給出 `ds = dω/(2π)`。因此三篇來源的正反轉換符號相同，S02 和 S03 可換成 S01 的角頻率慣例。

## 頻率響應（S03，§3.4，頁 103–104）

原文以輸入 v(t)、脈衝響應 h(t) 與輸出 w(t) 表示濾波。`w(t) = (h*v)(t)`，故原文的頻域式為 `W(s) = H(s)V(s)`，換成 Wiki 慣例為 `W(ω) = H(ω)V(ω)`。

原文將實數響應概括為沒有相位變化。依原文乘積式與本次人工核准的數學釐清，對輸入與輸出頻譜皆非零的頻率，`|W(ω)| = |H(ω)||V(ω)|`，且 `arg W(ω) = arg V(ω) + arg H(ω)（模 2π）`。

- H(ω) > 0 時，相位不變。
- H(ω) < 0 時，相位改變 π（模 2π）。
- H(ω) = 0 時，該頻率的輸出為零，相位未定義。
- 0/1 理想濾波器在 H = 1 的通帶原樣保留輸入，在 H = 0 的阻帶抑制該成分。

## 低通濾波器（S03，§3.4.1，頁 104）

- 原文首次定義：`H_LP(s) = 1，若 |s| < νc；H_LP(s) = 0，若 |s| ≥ νc`。
- Wiki 角頻率：`H_LP(ω) = 1，若 |ω| < ωc；H_LP(ω) = 0，若 |ω| ≥ ωc`。

通帶以零頻為中心，截止點 ±ωc 歸入阻帶。同頁後續展開式的最後一個分段用 >，漏列等號。依人工核准採用首次完整定義，也與同頁後續文字一致。

## 帶通濾波器（S03，§3.4.1，頁 104–105）

- 原文：`B(s) = H_LP(s−ν₀) + H_LP(s+ν₀)`。
- Wiki 角頻率：`B(ω) = H_LP(ω−ω₀) + H_LP(ω+ω₀)`，其中 ω₀ = 2πν₀。

將低通響應移到 ±ω₀，可在 ω₀ > ωc 時得到兩個分離的通帶。頁 105 的頻率響應圖展示兩個矩形通帶。脈衝響應圖的例題取 ν₀ = 10 Hz、νc = 2 Hz，對應 ω₀ = 20π rad/s、ωc = 4π rad/s。

## 高通濾波器（S03，§3.4.1，頁 106）

- 原文：`High(s) = 1 − H_LP(s)`。
- Wiki 角頻率：`High(ω) = 1 − H_LP(ω)`。

抑制零頻附近的成分，例如量測中的慢速漂移。依本條目低通定義取補數，高通在 ±ωc 的值為 1，與原文同頁註 7 一致。

## 陷波濾波器（S03，§3.4.1，頁 106）

- 原文：`Notch(s) = 1 − B(s)`。
- Wiki 角頻率：`Notch(ω) = 1 − B(ω)`。

取帶通響應的補數，抑制以 ±ω₀ 為中心的兩個通帶，其餘成分原樣通過。
