# 連續時間傅立葉轉換

## 1. 傅立葉級數與傅立葉轉換（S01，投影片 8.1–8.4、8.10、8.16–8.17）

講義將非週期波形 x(t) 以週期 T₀ 重複，形成可用傅立葉級數表示的訊號。當 x(t) 完整落在所取的一個週期內，週期訊號的級數係數為 aₖ = X(kω₀)/T₀，其中 ω₀ = 2π/T₀。T₀ 越大，頻率取樣間距 ω₀ 越小。在講義的極限推導中，離散合成總和轉成連續頻率積分。

## 2. 時域與頻域（S01，投影片 8.4–8.5、8.8）

時域的 x(t) 描述訊號隨時間的變化。頻域的 X(ω) 描述構成訊號的各角頻率成分，並可用幅度 |X(ω)| 和相位 ∠X(ω) 表示。反轉換把這些成分合成回時域。

## 3. 正轉換與反轉換（S01，投影片 8.4）

S01 使用角頻率 ω（rad/s），j 為虛數單位。積分範圍均為 −∞ 到 ∞。

- 正轉換（analysis）：`X(ω) = ∫_{−∞}^{∞} x(t) e^(−jωt) dt`
- 反轉換（synthesis）：`x(t) = (1/(2π)) ∫_{−∞}^{∞} X(ω) e^(+jωt) dω`

正轉換採負指數，係數為 1。反轉換採正指數，係數為 1/(2π)。這是 S01 的原始慣例，後續來源須各自比對。

## 4. 單邊衰減指數訊號例題（S01，投影片 8.4、8.8，例 4.7）

令 x(t) = e^(−at)u(t)，a > 0，u(t) 為單位階躍函數。由於負時間的訊號為零，套用正轉換可得：

```text
X(ω) = ∫_0^∞ e^(−at) e^(−jωt) dt
     = ∫_0^∞ e^(−(a+jω)t) dt
     = 1/(a+jω).
```

a > 0 使積分上限的指數項趨近零。講義以幅度與相位圖呈現這個頻譜。

## 5. 週期訊號的頻譜（S01，投影片 8.14–8.15、8.17）

週期訊號的頻譜可用 Dirac 脈衝列表示。若其傅立葉級數係數為 aₖ，頻譜的脈衝位於 kω₀，權重為 2πaₖ，即 `Σ_{k=−∞}^{∞} 2πaₖ δ(ω−kω₀)`。代入反轉換時，權重中的 2π 與反轉換的 1/(2π) 相消，回到傅立葉級數合成式。
