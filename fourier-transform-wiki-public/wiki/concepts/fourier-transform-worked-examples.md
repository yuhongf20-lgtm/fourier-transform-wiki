# 傅立葉轉換計算例題

## 公式慣例（S04，式 (38)–(39)，頁 21；S01，投影片 8.4）

S04 使用角頻率 Ω，原文的 X(jΩ) 在 Wiki 記作 X(ω)。兩者表示以實數角頻率為自變數的同一個頻譜。原文記號中的 j 無須再乘入自變數。

- 正轉換：`X(ω) = ∫_{−∞}^{∞} x(t)e^(−jωt) dt`。
- 反轉換：`x(t) = (1/(2π)) ∫_{−∞}^{∞} X(ω)e^(+jωt) dω`。

S02 使用一般頻率 f，S03 使用一般頻率 s。分別以 ω = 2πf 與 ω = 2πs 換元，反轉換的微分量便帶出 1/(2π)。四篇教材的正轉換指數皆為負，反轉換皆為正。（S02，投影片 3；S03，§2.1，頁 73。）

## A. 置中矩形脈衝（S04，§4.2 例 8，頁 23–24，圖 14）

令 T > 0。脈衝以 t = 0 為中心，在 |t| < T/2 時等於高度 a，其餘為 0。當 ω ≠ 0，對非零區間積分：

```text
X(ω) = a ∫_{−T/2}^{T/2} e^(−jωt) dt
     = a(j/ω)[e^(−jωT/2) − e^(+jωT/2)]
     = aT sin(ωT/2)/(ωT/2).
```

最後一步使用 Euler 公式。由於 z → 0 時 sin(z)/z → 1，因此 X(0) = aT，等於脈衝面積。

**Sinc 的兩種寫法（S04，例 8；S02，投影片 5；S03，§3.4.1，頁 104）**。非正規化 sinc 為 sin(z)/z，正規化 sinc 為 sin(πx)/(πx)，兩者在零點的值均以極限定為 1。令 z = πx，兩式相同。本頁無下標的 sinc 採**正規化**定義，因此上式也可寫作 `aT sinc(ωT/(2π))`。

## B. 脈衝寬度與頻譜主瓣（S04，§4.2 例 8，頁 24，圖 15）

對非零高度 a，令 `ωT/2 = ±π` 得到第一對非零零點 `ω = ±2π/T`。主瓣位於這兩點之間。固定 a 並令寬度由 T 變成 T/4，零點離零頻的距離變為 4 倍，零頻值變成 aT/4。

未來的互動圖解可用脈寬滑桿同步更新矩形脈衝、頻譜、零頻值和第一對零點。

## C. Dirac 脈衝（S04，§4.2 例 9，頁 24–25）

δ(t) 是廣義函數（分布），以對測試函數的抽取作用定義，沒有一般有限高度函數的逐點值。抽取性質為 `∫_{−∞}^{∞} δ(t)φ(t) dt = φ(0)`。套用到傅立葉轉換核，取出 t = 0 時的值 e^0 = 1，因此 `δ(t) ↔ 1`。

## D. 單邊衰減指數（S04，§4.2 例 11，頁 26–27，圖 17；S01，投影片 8.8）

u(t) 是單位階躍。對 a > 0，負時間的訊號為零，因此

```text
X(ω) = ∫_0^∞ e^(−at)e^(−jωt) dt
     = [−e^(−(a+jω)t)/(a+jω)]_0^∞
     = 1/(a+jω).
```

因 a > 0，被積函數的幅度 e^(−at) 可積分，上限項也趨近零。S01 已收錄 `e^(−at)u(t) ↔ 1/(a+jω)`。S04 提供逐步積分以及時域、頻譜幅度與相位的圖解。
